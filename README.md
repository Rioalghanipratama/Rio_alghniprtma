# Rio Alghani Pratama — Portfolio

Portfolio pribadi modern yang dibuat menggunakan React dan Tailwind CSS dengan konsep cinematic dark UI.

## ✨ Features

- Responsive modern layout
- Interactive UI animation
- Project showcase section
- Smooth scrolling experience
- Clean and minimalist design

## 🛠️ Tech Stack

- React JS
- Vite
- Tailwind CSS
- Lucide React
- React Icons
- Type Animation
